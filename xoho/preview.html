🏍️ Flux Utilisateur

① Splash → Onboarding → Login OTP

② Accueil Carte → voit les livreurs en temps réel

③ Crée un colis (3 étapes) → publie l'annonce

④ Clique sur un livreur → Fiche livreur → paye 100F → contact débloqué

⑤ Tracking → QR Code scan → livraison confirmée

⑥ Portefeuille : recharge MTN MoMo / Moov Money

🔒 Sécurité

• KYC : scan CIP + selfie obligatoire

• QR Code : scan départ + arrivée = preuve irréfutable

• Séquestre : paiement bloqué jusqu'à confirmation

• Commission : 10% prélevée côté serveur (Cloud Functions)

• Note "Gbê" : livreur < 3★ → banni automatiquement

📡 Stack Technique

• Flutter 3.x + Riverpod 2

• GoRouter navigation + deep links

• Firebase Auth, Firestore, Functions, FCM

• Google Maps dark style personnalisé

• qr_flutter + mobile_scanner

• MTN MoMo API + Moov Money API
